## 报告问题

先确认你使用的是哪个 Release，以及它是否包含所需功能；源码文档中的 1.0.0 目标功能
不会出现在旧 0.11.1-m10 APK 中。安装、签名与升级问题先阅读[安装说明](docs/INSTALLATION.md)。

在 [GitHub Issues](https://github.com/monet4070/ts3-mobile/issues) 搜索已有问题，
未找到后使用 Bug report。功能建议使用 Feature request。
请提供应用版本/源码提交、下载来源、正式或调试包、设备型号与 Android 版本，
以及音频路由、前后台状态、复现步骤、期望与实际结果。

更多选项 → 诊断可主动复制脱敏诊断。分享前检查日志、截图和剪贴板，删除私人服务器地址、
密码、身份、昵称与其他成员信息；不要上传身份文件、Keystore、签名私钥或完整抓包。
可以用 `voice.example.com`、示例昵称和虚构频道替代复现说明中的私人内容。

不要把安全漏洞发到公开 Issue。使用 [GitHub 私密安全报告](https://github.com/monet4070/ts3-mobile/security/advisories/new)，
流程见 [SECURITY.md](SECURITY.md)。

项目由社区维护，没有付费客服、承诺响应时间或全天候服务保障。Android 厂商、网络和服务器
权限会影响行为；支持范围和待验收项见[兼容性说明](docs/COMPATIBILITY.md)。
应用不会自动上传诊断，也不会通过仓库 Star 操作向维护者发送会话数据。

## English

Check the release version first: the 1.0.0 target features in source docs are not
in the older 0.11.1-m10 APK. Read [installation](docs/INSTALLATION.md) for upgrade
and certificate problems, then search [existing issues](https://github.com/monet4070/ts3-mobile/issues).
Use Bug report for defects and Feature request for proposals.

Include app version/commit, download source, release/debug package, device/Android
version, audio route, foreground/background state and precise reproduction steps
with expected/actual results. More options → Diagnostics lets you copy redacted
diagnostics manually. Review logs, screenshots and clipboard text before sharing;
remove endpoints, passwords, identities, nicknames and participant information.
Do not attach identity files, keystores, private signing keys or raw captures.

Report suspected vulnerabilities through the
[private security form](https://github.com/monet4070/ts3-mobile/security/advisories/new),
following [SECURITY.md](SECURITY.md). This community project has no support SLA.
[Compatibility](docs/COMPATIBILITY.md) records tested coverage and open acceptance.
The app does not upload diagnostics automatically.
