# TS3 Mobile 1.2.0

**2026-11-20 · versionCode 16 · Android 8.0+**

## 语音与蓝牙

- **蓝牙首播保护**：耳机已连接、但音频通道还没从待机恢复时，给系统更多起播时间，避免过早重建播放器、丢掉首句开头。已就绪时不会额外等待；耳机断开仍会安全静音，防止意外外放。
- **实时切换语音播放档位**：在 **设置 → 语音播放** 选择 **平衡（默认）** 或 **稳定优先**。稳定优先用少量额外延迟换取对语音包晚到的容忍度。保存后立即重置收听，可能短暂停顿，但无需重连服务器，不退出频道，也不重启麦克风。
- **与视频、音乐共存**：TS3 不再主动抢占音频焦点或将系统切进通话模式。语音与媒体一起播放，使用系统媒体音量。蓝牙收听时应用优先使用手机麦克风。

## 日常体验

- **麦克风音量和试音**：点击语音栏的麦克风图标，即可用竖向滑杆调节输入音量，不会因此开启麦克风。麦克风设置支持本地试音，不向频道发送声音。
- **设置、通知与聊天**：常用选项集中到独立设置页，聊天会话切换更简洁。连接通知可直接静音、恢复收听或断开连接；触发耳机保护后仍需回应用确认输出。
- **服务器和频道邀请**：支持打开、粘贴和分享 TeamSpeak 邀请链接。加入前先显示目标并请求确认，不会点开后自动连接。
- **诊断和更新检查**：改进音频诊断历史的加载，并区分更新服务器请求失败与发布信息异常。

## 安装与验证

- 1.1.0 用户可在应用内打开 **检查更新 → 下载 APK**，由浏览器下载后确认安装。也可从本页下载 `ts3-mobile-1.2.0-release.apk`、`SHA256SUMS.txt` 和 `BUILDINFO.json`。沿用正式包名和原签名，可直接覆盖升级；安装前请先断开服务器，不要卸载或清除数据。
- 蓝牙冷启动和热启动已在小米 14（Android 16）上对照排查，体验包已实听。首播保护不是对所有耳机或弱网场景的保证；稳定优先也不能补回实际丢失的语音包。若仍听到断音，可在诊断页标记并导出 JSON 反馈。
