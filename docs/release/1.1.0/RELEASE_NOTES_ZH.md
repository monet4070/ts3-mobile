# TS3 Mobile 1.1.0

**2026-11-09 · versionCode 15 · Android 8.0+**

## 更新内容

- **应用内检查更新**：从“更多选项 → 检查更新”查看正式版，可选择包含测试版并保存偏好。
  下载交给浏览器，不在后台轮询或自动安装。关闭固定在顶部；更新说明按 Markdown 渲染，展开后可随时收起。
- **离线音频诊断**：不接 USB 也能保存接收、播放、网络与路由的数值记录。
  听到断音后点“标记刚才断音”，结束测试后导出 JSON；正常断开或重开应用后仍可取回已落盘记录。
  不记录声音、服务器地址、身份或其他成员资料，不自动上传。
- **蓝牙误判修复**：区分耳机仍可用时的 SCO 空闲释放与真正断开，下一次播放取得音频焦点后恢复蓝牙。
  耳机真正丢失或意外回退仍保留安全静音保护。
- **界面与聊天**：麦克风设置分组更清晰，输入电平和门控阈值共用刻度；聊天采用左右气泡，搜索结果突出上下级关系和加入操作。
  支持保存浅色、深色或跟随系统外观。
- **日常使用**：调音参数跨重启保存；切换页面保留聊天阅读位置；增加后台私信汇总提醒、保存当前连接及按名称选择收藏频道。
- **身份备份与恢复**：提供自有 `.ts3mbak` 口令加密文件、回读验证、确认后导入和本地回退。
  备份不包含收藏和连接表单，不兼容桌面客户端身份文件；请单独保管口令。
- **音频隔离**：个人静音操作保留其他人的有效未混音音频和解码状态；共用输出退役仍可能产生间隙。

## 安装与升级

下载同一 Release 的 `ts3-mobile-1.1.0-release.apk`、`SHA256SUMS.txt` 和 `BUILDINFO.json`。
沿用原正式包名及公开签名，code 15 高于 1.0.0 / code 14，可保留原应用覆盖升级。
**安装前先断开服务器；不要卸载或清除数据。** 已装旧稳定版仍需先下载本版，之后可使用应用内检查更新。

首次启动不会自动连接，也不会自动打开麦克风。身份替换必须先检查并明确确认；本地回退不能替代外部备份。

## 验证与已知边界

此版本的源码、签名、自动化、最终包探针和 Xiaomi 14 升级结果见
[发布验收](https://github.com/monet4070/ts3-mobile/blob/v1.1.0/docs/release/1.1.0/CHECKLIST.md)，
确切源码提交与 APK 摘要见 `BUILDINFO.json`。

**本版不宣称移动网络断续已彻底修复。** 近期手机收听曾反馈暂时流畅，真实弱网问题尚未复现确认；
新增诊断用于下次故障定位。PLC、欠载等计数不直接等于网络丢包或可闻断音。
突然退出或调度/存储失败可能丢失末尾记录，诊断保留窗口通常约 10 分钟。
长时间锁屏、蓝牙热插拔、电量开销、更多厂商/Android 版本及独立安全审计仍有未覆盖范围。
