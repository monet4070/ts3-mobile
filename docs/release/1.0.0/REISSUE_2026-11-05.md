## 授权与版本策略

维护者因真实语音断续删除 11 月 4 日 code 13 的 GitHub Release。在调试包实机
修复后反馈“现在好多了”，要求重新发布，并明确选择继续使用 `1.0.0` 标签，
而不是建议的 1.0.1。此次按该授权把 `v1.0.0` 更新到经过 PR / CI 的修复提交。
这是撤回后重发的单次例外，不改变以后默认不移动公开 tag 的政策。

更新前的 tag 对象为 `d25094c25635e3bb44f218de10b9cee3abea2d3f`，
指向 `be1d6c2ff6834ea0a382503a1366064ac7526be5`。保留本机旧 tag 内容，
更新时核对远端对象，并对该确切引用使用带预期旧值的 force-with-lease；
发现其他人已改变 tag 时停止，不覆盖未知变更。`main` 仍经普通 PR 合入，不强推。

versionCode 从 13 提高到 14，版本名不变，正式应用 ID 和旧公开签名保持不变。
已安装旧稳定版的用户重新下载并覆盖安装，不需要卸载或清数据。旧 APK、摘要和
缓存源码压缩包不能用于验证新包；以新 `BUILDINFO.json` 的版本、源码和摘要为准。
需要重新取标签的源码使用者应有意识地更新本地 `v1.0.0`，不要混用旧检出目录。

- 生产代码：`PlaybackSession.kt` 保留短停顿前的绝对播放截止时间，最多追赶 50 ms；
  `VoiceReceiveQueue.kt` 统一真正超过 60 ms 的过期判定，避免负包龄误丢新包及 PCM。

  接收预算、Opus / RNNoise 或持久化配置变化，无公共 API 迁移。
- 文档：同步双语发布正文、README、安装、兼容性、安全策略、更新日志与本记录；
  code 13 原有验收保留为明确的历史，不将旧签名 APK 结果冒充新包验证。

生产文件各少于 250 行，职责不变，无需拆分。较大的 README 和架构文档只更新
版本摘要或音频契约，详细记录保持在独立文件；不进行与此次发布无关的结构重构。

## English

The maintainer withdrew the original November 4 code 13 release after an audio
regression, confirmed improved listening with the debug fix, and explicitly chose
to reuse `v1.0.0`. This one-off retargeting is guarded by the expected old tag object;
`main` still merges through PR and CI. Normal future releases keep immutable tags.

The replacement keeps versionName 1.0.0, the application ID and the public signing
certificate, while increasing versionCode to 14 for in-place upgrades. Download
the APK, checksum file and build information again; old code 13 assets and cached
source archives do not identify the replacement. Do not uninstall to update.

Playback pacing and negative-age packet expiry are fixed without altering codecs,
receive budgets, permissions, protocol or storage. Eleven independent regressions
cover both mechanisms. Fresh replacement-APK gates, probes and synthetic-data
upgrade checks are recorded separately from historical first-release evidence.
Real-device recordings used the debug fix and do not establish glitch-free
speaker output, full Bluetooth/background/load coverage or real-data retention
for the signed replacement. Private diagnostics and signing material are not assets.
