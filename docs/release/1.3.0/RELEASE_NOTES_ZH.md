# TS3 Mobile 1.3.0

**versionCode 17 · Android 8.0+ · 候选草稿（待正式签名、真机验收与最终 CI 完成后定稿）**

## 频道文件、附件与聊天

- **只读频道文件、聊天附件与头像图标**：支持主动浏览并验证下载频道文件与同服聊天附件（最大 20 MiB），先暂存核验长度，再由系统文件选择器导出保存；用户列表左侧展示头像，频道与用户可点击预览服务端图标。所有下载仅连接当前会话对端地址，兼容服务端空值、通配与双栈文件下发地址，不自动取件或跨服跳转。
- **可选本地聊天历史与格式优化**：新增默认关闭的本地聊天历史，可将符合条件的新文本加密保存在有限配额的本地档案中并支持离线浏览或清空；支持基础 TeamSpeak BBCode 展示与打开外链前地址核对，长按复制保留原始文本。

## 连接、浮窗与界面体验

- **连接悬浮窗（Connected Floating PTT）**：正式构建提供通知栏召回的连接悬浮窗与私有设置入口，支持可选按 Home 自动显示且绝不自动开麦；展开时对称展示频道名与发言者列表，仅按住说话模式可按压发话，试麦期间严格隔离麦克风归属。
- **收藏隔离与设置整合**：修改收藏地址或端口时自动清除草稿中的旧密码与默认频道（仅改默认频道时保留服务器密码）；收藏“立即连接”不会打断活动会话。统一语音、外观、历史、诊断和更新设置界面交互与大字号／窄屏适配；帮助说明收口至 **设置 → 帮助与关于 → 功能帮助** 按需查阅。

## 可靠性、音频与安全加固

- **会话并发与恢复加固**：收紧会话退出与重连交接锁边界，确保用户主动断开不再清除个人麦克风参数或阻塞后续连接；改进已识别握手定宽异常的有界重试缓解，并对未知失败保留清晰的不可盲目重试区分。
- **蓝牙与语音播放保护**：强化系统自动路由下的无回调蓝牙回退防护与空闲音轨回收，收紧抖动队列过期淘汰至 360 ms 防止久积旧音延迟播报；将本地试麦清理、诊断档案读取与备份规则完整排除列表对齐离线与隐私要求。
- **桌面 INI 导入边界**：标准 Release 构建默认关闭桌面 TS3 INI 预览导入入口（保留独立 Debug / QA 验证入口）。
