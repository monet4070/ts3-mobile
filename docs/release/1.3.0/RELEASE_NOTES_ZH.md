# TS3 Mobile 1.3.0 更新说明

**versionCode 17 · 要求 Android 8.0（API 26）及以上 · 对比 1.2.0（versionCode 16）**

[English](RELEASE_NOTES.md) · [使用指南](../../USER_GUIDE_ZH.md) · [安装与升级](../../INSTALLATION.md) · [兼容性与验证](../../COMPATIBILITY.md) · [验收状态](../CANDIDATE_STATUS_2026-11-25.md)

1.3.0 是基于 1.2.0 的功能与稳定性更新，带来**连接浮窗 PTT**、**输入与输出设备独立选择（含 LE Audio 与可选蓝牙通话耳机麦）**、**只读频道文件与聊天附件**、**可选本地聊天历史**、**收藏凭据隔离与离线频道列表**、**按需功能帮助**，并重点加固了**Wi-Fi 与移动数据切网保持**、**蓝牙防外放**和**会话退出／重连并发稳定性**。

---

## 相比 1.2.0 的新增功能

### 连接浮窗 PTT

- **在其他应用上方发言与查看发言人**：加入频道后，在 **更多选项 → 设置 → 浮窗 PTT** 授予悬浮窗权限即可手动开启，也可从连接通知点 **开启浮窗** 召回。
- **标准与极简两种样式**：在预览卡片中选择 **标准浮窗**（默认，收起时显示当前发言者昵称）或 **极简浮窗**（收起后仅保留两个图标）。
- **紧凑单行发言栏**：拖动左侧区域移动浮窗，轻点展开可查看最多 3 位实时发言者（更多人数显示 `+N`）并切换麦克风模式；无人发言时保持固定高度，按钮不跳动。
- **可选退到后台自动显示**：开启 **退到后台时自动显示浮窗**（默认关闭）后，在已加入频道且麦克风空闲时，回桌面或从主界面按返回（Android 12+）会自动显示浮窗。显示与召回都不会自动开麦。
- **安全边界**：仅 **按住** 模式按住右侧按钮发话、松手停止；其他模式下该区域仅展示实时麦克风状态。锁屏、离开频道或返回应用会结束浮窗采集；本机试麦占用输入时，浮窗不会同时开始采集。

### 只读频道文件、同服聊天附件与服务端图片

- **浏览与下载频道文件**：加入频道后进入 **更多选项 → 频道文件** 浏览并主动下载；聊天中支持的同服附件可点 **下载附件**。
- **校验后再保存**：单个文件上限 **20 MiB**，仅从当前已连接服务器取件。应用会核验实际接收长度，再让你通过 **保存已验证文件…** 使用 Android 系统文件选择器保存；界面旋转或重建后仍可继续保存。
- **头像与频道图标预览**：在 **用户** 列表点已有头像可放大预览，界面上显示的自定义频道图标也可点按预览；频道成员行仍保留语音状态图标。图片仅在当前会话内存中缓存。
- **权限与限制**：能否查看或下载由服务器权限决定；不支持上传、改名、删除、自动下载或跨服取件。

### 可选本地聊天历史与聊天展示优化

- **默认关闭的本地加密存档**：在 **更多选项 → 设置 → 本地聊天历史** 主动开启后，仅将符合条件的新文本加密保存在本机（独立 Keystore 密钥，排除云备份与换机迁移），断开连接后可通过 **浏览已保存消息** 按当前身份离线查看。
- **配额与清理**：默认仅保留最近 7 天、总计最多 500 条 / 512 KiB 编码记录；支持删除单个会话、清空全部或关闭并删除全部。不补存旧消息，不保存草稿、戳一下、未确认发送、密码或附件文件内容，也不云同步。
- **BBCode 展示与外链核对**：聊天支持基础 TeamSpeak BBCode（粗体、斜体、代码与显式 HTTP(S) 链接），长按复制保留原文；打开外部链接前会先显示目标地址供核对，不自动拉取链接预览。

### 收藏凭据隔离与离线频道列表

- **修改目标自动清除旧凭据**：编辑收藏的服务器地址或端口时，自动清除草稿中的旧默认频道及服务器／频道密码；仅修改或清除默认频道时，仅清除频道密码、保留服务器密码。取消编辑不改动原收藏，未编辑的收藏和独立连接表单不受影响。
- **更安全的快捷连接**：收藏卡片的 **立即连接** 不会打断或替换当前活动会话。
- **离线保存频道列表**：编辑与当前连接匹配的收藏时，可在 **更多设置** 中选择 **保存频道列表供离线使用**（单端点最多 100 个频道 ID 与路径，最多 6 个端点，独立加密存储），离线时通过 **浏览已保存频道** 选用或清除。

### 输入与输出设备与蓝牙耳机麦克风支持

- **独立选择麦克风与播放设备**：新增 **更多选项 → 设置 → 输入与输出设备**，分别列出系统可选的物理麦克风（按已知位置标注手机底部／顶部／正面／背部麦克风，重名自动编号，不显示原始设备地址）与播放设备，并附带只读的 **实际使用的音频设备** 面板（现可区分蓝牙媒体 A2DP、蓝牙通话 SCO 与 **蓝牙 LE Audio**）。
- **蓝牙 LE Audio 独立收发**：当手机与耳机支持 LE Audio 时，可分别选择 **LE Audio 耳机麦克风** 与 **蓝牙 LE Audio** 播放输出，无需切入通话模式或申请音频焦点。
- **手动可选「蓝牙通话（使用耳机麦克风）」**：当系统暴露传统蓝牙通话设备时，播放设备列表提供独立的 **蓝牙通话（使用耳机麦克风）** 选项。应用绝不自动选择该项，也不会跨会话保存；选中后耳机同时负责通话播放与收音（传统蓝牙通话模式可能导致音质下降），等待 SCO 播放确认且不使用回退麦克风；选回普通蓝牙播放或断开服务器即自动退出通话模式并恢复先前麦克风选择。
- **热插拔与安全边界**：设备 ID 为临时状态，不持久化保存；外接／指定麦克风断开时自动切回 **自动选择麦克风**，蓝牙输出断开仍触发防外放安全静音。

### 按需功能帮助与设置整理

- **按需功能帮助**：新增 **更多选项 → 设置 → 帮助与关于 → 功能帮助**，涵盖连接、邀请、收藏、身份备份、试麦、音频路由、浮窗、聊天、文件与排障说明。支持离线阅读与页面控件高亮引导，启动时不会自动弹出，也不会代用户执行任何操作。
- **语音播放与实际音频设备面板**：**设置 → 语音播放** 对未设置用户默认采用 **稳定优先**（不覆盖已有选择）；**实际使用的音频设备** 面板分别显示所选输出、已确认实际输出（含蓝牙媒体 A2DP、蓝牙通话 SCO 与蓝牙 LE Audio）、实际录音输入和系统麦克风静音状态（未录音不误判为已静音）。
- **身份与设置交互统一**：**身份与备份** 直接提供 **创建加密备份** 与 **从备份恢复** 入口（仅本机存在旧副本时显示 **恢复上一个身份**）；统一语音、外观、历史、诊断与更新页面的开关、读数与操作样式，改善窄屏和大字号下的换行适配。标准正式包默认关闭桌面 TS3 `.ini` 预览导入（仅 Debug / 专用 QA 构建开放）。

## 相比 1.2.0 解决的问题与稳定性加固

### 网络切换与重连体验

- **Wi-Fi 与移动数据短暂切网保活**：遇到短暂默认网络中断时（最长 2 秒，系统明确阻断除外），先保留原服务器会话、频道快照和音频；新网络恢复后先探测原会话，若原会话能正常应答则继续沿用、无需重新连接（期间语音可能短暂停顿，无法维持时再走正常断线恢复）。
- **修复切网后的同身份连接拒绝误判（错误码 521）**：修复底层初始化阶段服务器拒绝可能被线程中断掩盖为普通可重试错误的问题。现在可准确识别同身份连接限制（`521`）；若发生在已确认切网后的自动重连阶段，应用会等待 60 秒后自动再试一次，避免短时间连续失败（手动连接和同网冲突仍立即停止并给出等待提示）。
- **已识别握手定宽异常缓解**：在保持固定 `ts3mobile-1` 协议依赖的前提下，为已识别的握手定宽编码异常补充有界重试缓解。

### 蓝牙防外放与语音播放

- **持续检测无回调蓝牙回退**：在输出边界持续检查实际播放路由，及时识别系统未发送回调的蓝牙自动回退并触发安全静音。
- **清理延迟就绪的空闲蓝牙音轨**：避免蓝牙延迟就绪后、发言已结束时遗留空闲音轨。
- **收紧过期语音淘汰上限至 360 ms**：防止积压的过期语音帧延迟播报，并将过期语音与输出设备停滞分开处理。
- **主线程解耦**：将本机试麦清理与音频诊断档案读取移出主线程，减少界面卡顿风险。

### 会话生命周期、存储与诊断可靠性

- **会话退出与连接并发加固**：用户主动断开不再清除个人麦克风调音参数或中断诊断记录；退出清理受时间预算保护，避免旧连接失败或过期回调关闭替代会话、停止新会话音频或导致界面卡在“连接中”。
- **重连与频道操作边界**：重连交接期间不再漏掉二次断线；频道订阅和频道切换均设等待上限，未获服务器确认的切换不会静默重复。录音释放失败时会干净结束当前连接尝试，同时仍完成播放与路由清理。
- **聊天历史、收藏与文件保存保护**：系统时钟回拨不再误删本地聊天记录，清空记录后立即释放队列容量；收藏保存超限时保留旧档案；若导出文件写入可能不完整会给出警告并允许改存到其他位置；诊断导出按次隔离。
- **诊断与隐私规则补齐**：仅恢复完整落盘的诊断批次，明确记录漏采的播放代际，服务销毁不再阻塞等待落盘；新增脱敏协议计时桶与设备类别诊断字段（精确 UDP 计时仅在独立本地 QA 构建中可用）；补充将播放和更新配置 DataStore 纳入 Android 备份排除规则；快速状态变化后核对连接通知的最终操作，已销毁服务不会重启播放。

## 从 1.2.0 升级

- **升级方式**：沿用正式应用 ID（`io.github.ts3mobile.app`）与原公开签名，从 1.2.0（code 16）覆盖升级至 1.3.0（code 17）。
- **注意事项**：升级前请先在应用或通知栏正常**断开服务器**；**不要卸载应用或清除存储**，以免丢失本机 TeamSpeak 身份、收藏与连接表单。详细校验步骤见[安装与升级](../../INSTALLATION.md)。

## 验证状态与已知边界

- 最终包沿用公开签名，并在 API 36 模拟器通过 1.2.0 覆盖安装、合成文件保留和冷启动检查。最终包的实服双向切网、物理蓝牙组合和真实用户数据升级仍有未复验项，详见[1.3.0 验证记录](../CANDIDATE_STATUS_2026-11-25.md)与[兼容性与验证范围](../../COMPATIBILITY.md)。
- 频道文件与聊天附件均为只读下载（限 20 MiB），不支持上传；标准发布包不包含桌面 `.ini` 导入和 Debug 本机录音实验室；本机仅支持单一活动服务器连接。
