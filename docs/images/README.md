# Documentation images

`bookmarks-and-editor.png` shows the current Compose bookmark list and editor on
the Xiaomi Android 16 device, arranged into one illustration for the README.
It was prepared on 2026-11-02 from the offline `BookmarkListTest` and
`BookmarkEditorTest` fixtures.

`interface-overview.png` was arranged on 2026-11-03 from three existing physical
device fixture captures recorded on 2026-11-02: the connection page from
`WarmSurfaceTest`, and the channel page and disconnected More menu from
`AwayAndSupportTest`. The channel fixture shows confirmed Away; the menu fixture
is disconnected, so its session-dependent entries are disabled. They illustrate
different UI states, not one simultaneously captured screen.

Only scaling and composition were applied, with bilingual panel labels. No UI
controls were fabricated. The original captures remain in ignored local build
evidence folders; the repository includes only the reviewed documentation image.

The addresses are reserved example domains; names, nicknames and entries are
synthetic. No live server, participant data, device serial, notification shade
or credential appears in the image. It illustrates the current UI, not a proof
of final 1.0.0 binary acceptance.
