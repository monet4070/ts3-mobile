# A2 浮点增益与限幅执行记录

## 实现范围与拆分评估

承接 [A0/A1](AUDIO_A0_A1_2026-10-24.md)；本阶段的实现位于 audio-opus。
采集顺序为 RNNoise（可关闭）→ float 手动增益 → 限幅前门控电平支路与限幅主路 → 原有起声选择 → Opus。
播放由 PlaybackStreams 持有独立 ParticipantGainMixer；每个参与者的增益包络和总线限幅状态属于该会话。
相关生产文件均小于 300 行；提取 GainEnvelope、PcmLimiter，不扩大播放器或服务职责。
公共 API、设置格式、默认音源、Opus 参数和依赖不变。

## 本轮实现选择

- 非静音增益变化按采样率计算 20 ms 线性斜坡；首次音量直接取设置值；0% 立即生效。
- float 累加采用固定单位增益，取消按路数归一；单人不衰减，额外静音路不改变其他声音。
  多人低电平相加会比旧的 `1/sqrt(N)` 更响；多人过载由共享总线限幅控制。
- 限幅原型为零前视峰值检测、即时 attack、5 ms 峰值保持、80 ms 指数释放、-1 dBFS ceiling。
  ceiling 向下取为可表示的 PCM16 幅值 29,204（-1.00015 dBFS），最终转换采用四舍五入；
  释放包络用 Double，避免 Float 在接近单位增益时停止恢复而留下永久衰减。
  不缓存音频，因此新增算法延迟为 0 样本，待排出的 DSP 尾样本为 0；有效短尾仅输出一次，余下补零。
  该方案可避免前视缓存与门控错位，但过载突变仍可能产生失真，需用合成信号量化并由后续真机听测决定参数。
- 门控 RMS 对手动 float 增益作等价 PCM16 饱和值计算，保留旧阈值静态含义，主路仅在限幅后转换 PCM16。
  起声 120 ms、2 帧 attack、15 帧 hold 和 6 dB hysteresis 保留。
- 设置修订清空部分帧、起声和限幅状态，仅保留增益包络当前数值以执行斜坡，不保留旧音频。
  会话停止、重建清除 DSP 状态；自然排空继续使用 A1 的实际接受样本计数。

### 信号与状态证据

- 固定种子 24、±5,000 PCM 幅值的宽带输入，100% 输出逐样本一致，幅度误差 0 dB、算法延迟 0 样本。
  初次延迟用例使用正弦发生整周期相关歧义，已换成唯一相关峰的确定性宽带信号。
- ±满幅 × 16 的八路同相最坏输入被限在 ±29,204，整数满幅削波样本为 0。
- 合成正弦输入峰值 60,000，处理 1 秒，取后 0.5 秒计算第 2–10 次谐波 RMS / 基频幅度：

| 频率 | 限幅 THD | 整数硬削波对照 THD |
| --- | --- | --- |
| 100 Hz | 0.000293% | 21.0559% |
| 1,000 Hz | 0.000852% | 20.9458% |

这些是稳态合成音的窄范围测量，不是语音可懂度、瞬态失真或主观听感结论。

- 24/48 kHz 的包络测试验证 20 ms 斜坡、5 ms 保持与 80 ms 指数释放；生产 I/O 仍为 48 kHz。
  过载后两秒静音再输入低电平可逐样本恢复单位增益；此用例曾捕获 Float 残余衰减，修正后通过。
- 覆盖跨 tick 斜坡、斜坡中途改目标、即时静音/解除静音、独立参与者、会话重置、额外静音路、
  新路渐入/渐出、120/240/479/480 短尾与一短一长组合；无尾部重复或额外 DSP tick。
- 覆盖限幅前 gate、阈值上下 1 dB、2 帧 attack、15 帧 hold、120 ms 起声、0%、
  设置修订丢弃旧 partial/onset/限幅状态以及修订期间增益斜坡。
- 真实 JNI 用例验证编码前 PCM 峰值受限，Opus 编码/解码帧数正确；有损编码后的峰值不作为编码前 ceiling 的保证。
  A1 原有十分钟虚拟播放轨迹继续通过，保持 28,800,000 样本恰好交付一次、无 PLC、无排空超时。

## 剩余验收与下一阶段

A2 的离线实现已完成，限幅参数保留实验状态。单位增益求和使多人低电平比旧归一更响；
强信号会通过共享限幅影响同时播放的弱信号。零前视的即时 attack 仍可能产生瞬态失真，
需要真机素材听测和输入音源校准决定是否采用至多 5 ms 的前视方案。
本轮未补齐 A0 的实际 stereo/music/DTX codec fixture、end-marker 互通或真机音源测量，
这些事项仍保留在 A0/A1 记录中。APM、Opus 升级和自适应 jitter 属于后续阶段；
输入音源校准、听感、真机时延/功耗仍待验收。
下一实现阶段为 A3 APM 对照原型，先固定依赖与参考流时钟/代次边界，再做离线合成回声验证。
