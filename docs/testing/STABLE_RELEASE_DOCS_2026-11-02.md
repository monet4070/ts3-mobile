## 理解与改动

项目保持 Android Compose → 服务控制器 → JVM 协议/音频适配的模块边界。
本轮未修改生产代码、测试源码、版本或签名配置，保留之前尚未提交的全部 UI/功能工作。
[ADR-0019](../decisions/0019-first-stable-release-documentation.md)记录文档职责拆分及风险。

- 生产代码：无本轮新增修改。
- 测试源码：无本轮新增修改；文档命令的模拟检查只保存在忽略的 build 目录。
- 文档：重写双语 README 和当前更新日志；归档原开发记录；新增双语用户指南、故障排查、
  安装升级、兼容性、支持、中文隐私、文档导航、示例截图和来源说明；补齐双语 Release
  正文、发布清单、签名/资产/上线手册，更新架构、安全、许可引用与历史发布计划入口。
- 配置：仅 GitHub Issue 表单的说明和支持/私密安全链接；无应用构建、权限、依赖或 CI 行为变更。

核对代码时同时修正两处旧说明：频道详情入口已移除，个人静音/音量保留在服务内存而非跨进程落盘。
后台戳一下通知、外部 GitHub 跳转和删除本机身份的影响已在中英隐私说明中同步。
