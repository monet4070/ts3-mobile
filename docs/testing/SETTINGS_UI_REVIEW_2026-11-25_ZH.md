# 设置页面逐项复核 · 2026-11-25

沿用 TS3 Mobile 浅色／深色主题、应用线框图标和卡片层级，不把版本号放在设置首页。除浮窗自动显示外，不改变已有偏好、权限语义或身份文件格式。

| 首页入口 | 复核和调整 |
| --- | --- |
| 麦克风设置 | 保留试麦、增益和音量门控控件，复用整行可点的开关，设备回声消除实际状态紧跟选项。 |
| 语音播放 | 把可选播放方案与实际设备分开；所选输出、实际输出、实际输入和系统静音分别列出。 |
| 浮窗 PTT | 自动显示、当前会话／手动开启、悬浮窗权限分组。开启一次自动显示后，按 Home 静默显示；返回应用即收起。 |
| 私信通知 | 核对仍直达 Android 系统通知渠道，权限和系统页面不在 App 内重复实现。 |
| 外观 | 延续浅色／深色／跟随系统的实时色板；加载、失败、重试与其他设置使用相同通知／操作样式。 |
| 身份与备份 | 当前身份、导出／恢复分段选择、加密备份、可选桌面导入与本机旧身份分区；恢复确认中分卡比较当前／候选身份。 |
| 本地聊天历史 | 本机保存开关与隐私说明同卡；浏览和删除分开；会话名与服务器副标题分层。 |
| 后台语音检查 | 电池与设备读数对齐，CPU 唤醒开关与限制说明同组，Android 入口保持独立。 |
| 诊断 | 标记、复制和保存同组并靠近脱敏说明；音频与连接数据分卡。 |
| 检查更新 | 版本只在更新页；共用开关与加载／错误提示，保留可单独展开的更新说明。 |
| 项目入口 | 外部浏览器行为不变。 |

验证范围包括中英文、浅色／深色、320 dp 宽和 1.8× 字体放大。宽屏读数显示标签和右侧值，窄屏大字改为上下排列；设置标题支持两行。快照使用合成身份，不关闭实际身份页的 `FLAG_SECURE`。

自动浮窗通过无声 API 35 模拟器使用合成会话测试：关闭开关时按 Home 不出现，从主界面连续召回、从浮窗设置页离开、返回应用收起，进入身份页不显示。自动展示不录音、不供帧。实际发话与 OEM 行为尚需真机复测。

最终回归：76 项设备测试、493 项 App JVM 测试通过；Kotlin 格式检查、Debug／Release Lint、混淆 Release 和独立开发签名 QA 构建通过。普通 Release 未包含本机试麦实验室。未发布到公开渠道。
