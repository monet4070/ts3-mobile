# 2026-10-18 R8 Release 短时真机验收

## 范围

用户授权约十分钟内验收，现场不方便发声，服务器只存在用户自己的两个客户端。
目标为 GitHub issue #3 的实际 Release 连接路径、界面/后台短时稳定性、正常断开与重连、
表单记忆。此验收不要求用户发声，也不构成双工通话音质、Bluetooth 或长时间稳定性验收。
设备为 Xiaomi 23127PN0CC、Android 16 / API 36；issue 原报 Android 14 不在本轮覆盖范围。

## 产物与签名

使用当前工作树开启 R8 的 Release 产物，versionCode 11 / 0.11.0-m10。
项目尚未配置独立正式发布密钥。本次使用手机既有应用一致的本机 Android debug 证书，
对 Release APK 签名并覆盖安装；应用代码保持 Release 优化及非 debuggable 标记。
这是 Release 代码路径验收，不是正式发布签名审核，也没有发布 GitHub 资产。
已验证签名前后每个 classes*.dex 内容一致；APK 哈希与本机证据单独保存在忽略目录。

本轮未改生产代码、测试源码或配置，只生成本地验收包、测试脚本和此报告。

两次退出从 EXIT_STARTED 到 EXIT_SERVER_CONFIRMED 的事件间隔分别为 62 毫秒、65 毫秒。界面自动化每次需要数秒抓取视图，其耗时不等同于协议退出耗时。

## 验收结论与边界

当前 Release 的 issue #3 修复已通过实际服务器连接验收，可以将其视为该缺陷在本机上的验证通过。
本轮没有主动触发 clone 限制或 ban，只有两次人工连接；没有要求用户发声或操作对端。
未完成 Android 14 原报设备、真实双向音频听感、30 分钟后台、物理 Bluetooth/热插拔、
密码频道恢复及正式发布密钥审核。小米桌面划掉任务的进程先被杀行为没有在本轮修复或复测。
这些限制仍见 M11 发布清单，本轮通过不代表全部正式 Release 门禁已完成。
