# TeamSpeak 戳一下交付

日期：2026-10-23（Asia/Shanghai）。源基线为 `c83aa45051bdc32cf8a090c082363bca16e356fa`
及尚未提交的 F1a/F1b 工作区。按用户“戳一下功能能不能做”的追加要求实现，继续采用离线验证。
本次不连接真实服务器，不发送真实私信或 Poke；不发布、不提交，不推进收藏或语音激活。

## 功能

- 用户页 → 目标用户菜单 → 戳一下；留言可选，最多 100 UTF-8 字节，保留首尾空白及 Unicode。
- 弹窗打开时固定本次手动会话、连接尝试、客户端 ID 和稳定 UID；自身、缺少可靠 UID、重复映射、离线、身份变化或重连后不可提交。
- 单独使用 `clientpoke clid=... msg=...`，发送后进入对应私聊显示结果；不借用私信命令，也不清空任何文字草稿。
- 复用一次待确认发送、服务器接受/拒绝/未知状态和无自动重试规则；权限不足有固定提示。
- 收到 Poke 显示应用内弹窗、释放 PTT，并在对应私聊保留独立类型的记录和未读；不改变常开麦克风模式。
- 最新提示只引用已保留消息的数字 ID；关闭旧提示不能误关新提示，历史淘汰/会话关闭时也不会额外留存其正文。
- 沿用最多 20 会话、500 条 / 2 MiB 总消息预算和 16 KiB 单条接收上限；满会话时有固定容量提示。
- 没有声音、振动或新增 Android 文本通知。未发送留言不进入 SavedState；退出、终态、新手动会话及进程结束沿用聊天清理规则。
