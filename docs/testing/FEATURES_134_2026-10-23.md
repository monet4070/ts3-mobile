# 用户选定的 1 / 3 / 4 功能交付

日期：2026-10-23（Asia/Shanghai）。基于 `main` / `c83aa45051bdc32cf8a090c082363bca16e356fa`
及未提交的聊天、私聊、戳一下、麦克风工作区。用户只选择：服务器收藏、暂离/静音状态同步、
频道信息与快速搜索。身份导入导出、好友/屏蔽、管理操作、连接质量面板及文件传输移出范围。
原有功能保留，不提交、不推送、不发布、不覆盖手机原包；继续采用离线验证。

## 1. 服务器收藏和快捷连接

入口为连接页“选择收藏服务器”，或更多选项 → 服务器收藏。

- 最多 50 项，支持新增、编辑、填表、快捷连接和带确认的删除；保存顺序保持稳定。
- 新增从当前表单提取地址、端口和昵称，不自动搬运密码。可以先选择最近服务器再新增。
- 保存名称、昵称及可选默认频道 ID；频道信息窗口可查看 ID。
- 勾选“记住服务器与频道密码”才保存两类密码，整份快照独立 AES-GCM 加密。
  关闭记住后两类密码从收藏快照中删除，包含重开文件后的验证。密码上限为各 1024 UTF-8 字节。
- 收藏使用单独 DataStore 文件、Keystore key alias、schema v1，不改已有表单、历史或身份格式。
  首次加载为空，不迁移旧数据；删除收藏不删除独立表单记忆、历史或身份。
- ID 与 revision 校验拒绝过期编辑/删除；读取、解密或写入失败明确提示，损坏文件不自动覆盖为空。
- 连接期间可管理收藏，但填表/快捷连接停用；先明确使用现有“断开”退出旧服务器，再连接收藏。
  Activity 在提交时再次检查当前连接阶段，未绑定服务时也不会启动收藏连接。
- 默认频道及频道密码通过既有频道恢复器进入；普通连接重置目标，避免继承上一收藏的频道或密码。
  默认频道拒绝或无效时保留服务器连接并显示错误，不声称进入成功。

编辑器正文可滚动，密码草稿仅在当前窗口内存，不写入 Activity 保存状态。表单自身的加密记忆仍
独立存在，界面明确说明：从收藏取消记住密码不会抹掉其他存储中的表单密码。
本轮不新增排序、云同步、多身份或并发服务器连接。

## 3. 暂离和服务端静音状态

更多选项 → 暂离与状态，可设置暂离及最多 256 UTF-8 字节的留言。暂离不自动停麦。

- 通过 `clientupdate` 同步 `client_away`、`client_away_message`、输入和输出静音标记。
- 麦克风明确关闭、缺权限或存在采集错误时输入静音；松开 PTT 和安静的音量门控监听仍表示可用，
  不随 20 ms 帧或瞬间发声反复发送静音切换。收听静音跟随本地播放控制。
- 本地静音/停麦先执行，服务端拒绝或超时不会撤销本地操作。
- 显示同步中、服务器已接受和未确认；未知结果不当作成功，可由用户主动重试。
- 只对从未认领的 Busy 请求做短暂、有界重试；已认领后超时不自动重发该请求。
  新连接应用当前期望状态，旧连接/旧期望的返回不能覆盖新状态。
- 取消暂离显式发送空留言。收到的暂离状态和留言显示在用户列表，兼容缺失字段。
  自己的暂离留言仅在服务内存，不进入日志或持久化；新手动连接恢复默认暂离状态。

服务器接受只代表命令响应成功，未实测其他真实客户端的最终显示。

## 4. 频道信息、搜索与加入

- 频道行的信息按钮，或更多选项 → 查找频道与用户。
- 详情按需发送有时限的 `channelinfo cid=...`，显示 ID、主题、纯文本描述、当前人数及人数上限。
  未提供、已删除、请求失败/权限不足均不伪造值；支持重试。
- 描述最多 16 KiB，主题有界；不执行 HTML/BBCode，不自动请求远程图片或 URL。
- 本地搜索当前快照的频道名/已提供主题和用户昵称，忽略大小写，最多各 50 项，查询最多 128 字符。
  查询只在弹窗内存，搜索本身不发网络请求；键盘“搜索”可收起键盘查看结果。
- 加入用户频道前按当前客户端 ID + 稳定 UID 重新解析频道，拒绝复用 ID、缺 UID 或已离线目标。
- 密码频道沿用密码弹窗；连接阶段变化时关闭查找/加入窗口，旧详情响应不会重开已关闭的窗口。
- 原频道树单击展开、双击加入、聊天/私聊/Poke 与麦克风功能保留。

## 代码、测试、文档与配置

生产代码集中在 `bookmarks/`、`discovery/SessionSearch`、`SessionControlsController`、
独立收藏/暂离/详情/搜索弹窗及 `InputDialog`。`MainScreenAppBar` 从主界面提取，保持主界面
低于优先评审的 300 行边界。Activity、Service 和连接协调器仅增加必要接线、状态和默认频道种子。

协议增加可缺省为 Unsupported 的状态/详情端口，模型/config 新字段均为尾部默认参数；
所有模块一起重编译，不承诺预编译消费者的 ABI。`BoundedSessionCommands` 从文字命令提取，
文字、Poke、状态和频道详情共用命令认领、FIFO、单 worker、deadline 和中断规则。

新增独立 JVM codec、收藏 controller、选中收藏填表、搜索/UID 解析、状态 controller 和 pinned
命令测试；补默认频道恢复回归；Android 侧新增 7 项功能 UI 和 3 项 scratch Keystore/DataStore 检查。
Keystore 测试只使用独立缓存文件，不读取/删除真实收藏、表单、历史或身份文件，不删除生产密钥。

配置只新增 `ts3_bookmarks.preferences_pb` 的备份/设备迁移排除规则；权限、依赖、生产包名和发布版本不变。
文档同步 README（中/英）、PRIVACY、ARCHITECTURE、CHANGELOG、协议 README、范围/执行计划和
[ADR-0017](../decisions/0017-bookmarks-presence-channel-discovery.md)。
