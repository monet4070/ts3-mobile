# 同身份连接数限制：等待与退出指导

> Historical implementation: automatic clone-limit retries described below were removed on 2026-10-18. See [ADR-0011](../decisions/0011-manual-refusal-and-form-memory.md) and the [current report](../testing/MANUAL_RETRY_MEMORY_VOICE_2026-10-18.md).
日期：2026-10-18。延续[任务移除真机调查](TASK_REMOVAL_DEVICE_2026-10-17.md)。

## 用户可见变化

已识别的同身份连接数限制不再回退显示 `too many clones already connected`。
中英文提示覆盖准备重试、下一次重试、离线等待和重试超时四种状态，说明：

- 服务器曾报告同一身份的连接数已满。刚从后台划掉应用时，旧连接可能尚未释放；
  也可能是其他客户端仍在使用同一身份，不断言一定是残留会话。
- 本次最多自动重试 60 秒，可以点击“取消重连”。离线等待也计入同一个窗口。
- 服务器决定旧连接何时释放，实际等待可能更长，不承诺 60 秒后一定连接成功。
- 超时后检查其他同身份客户端，按需断开；如果刚强制关闭应用，稍后手动重连。
- 下次先点击应用内或通知栏“断开连接”，等待完成后再划掉应用。

准备重试时的中文示例：

> 正在等待此身份的可用连接，准备重试。
>
> 服务器曾提示此身份的连接数已满。如果刚从后台划掉应用，上一次连接可能尚未
> 释放；也可能有其他客户端正在使用同一身份。
>
> 本次最多自动重试 60 秒，可随时点击“取消重连”。旧连接何时释放由服务器决定，
> 实际等待可能更长。
>
> 下次退出请先点击应用内或通知栏的“断开连接”，等待断开完成后再划掉应用，
> 避免旧连接暂留。

## 实现范围和兼容性

`ClonesRecoveryPolicy` 与提示使用同一个 `CLONES_RECOVERY_BUDGET_MS` 常量，
避免重试策略和显示时间各自维护数值。时长、退避、取消行为及服务器错误分类均未改变。
仅测试使用的自定义恢复时长不属于用户配置；产品仍使用同一默认值。

`UserMessageText` 在 Android 边界组合本地化的状态、可能原因、等待/手动操作和
退出指导。通知继续使用同一个消息解析入口。缺少服务消息但带有 `CLONES_LIMIT`
分类的状态也会获得本地化指导，不直接显示协议技术文字；未分类的其他错误保留
原有处理。

状态提示从连接表单外移到表单的滚动区域，取消三行截断，保证长说明可以读完，
取消/重连操作仍可到达。`MainScreen` 公共参数没有改变，内部表单仅增加带默认值
的文本参数。没有协议 API、存储格式、依赖、权限、签名或版本配置变更。

修改均位于现有短文件，不扩展超长协调器或恢复引擎；不需要在本轮引入新的拆分迁移。

## 回归和验证

新增独立 `ConnectionLimitGuidanceTest`，使用离线 fixture 和模拟器，不访问服务器
或手机身份：

1. 两种语言的四个恢复状态均包含时长、退出指导和其他客户端的可能性。
2. 英文重试说明在 1.8 倍字体下无截断，“取消重连”可滚动到并执行。
3. 中文超时说明在 1.8 倍字体下无截断，“重新连接”可滚动到并执行。
4. 缺少服务消息的已分类错误仍显示指导，隐藏原始英文拒绝文字。

旧实现的四项检查中三项失败：缺失等待/退出说明、中文长文字被截断、分类错误
回退显示技术报错。修正后四项均通过。

- 完整离线 Compose 套件：25 项通过。
- 最终资源措辞调整后：四项指导回归再次通过。
- 应用 JVM/单元测试：165 项通过。
- 全仓 Kotlin `quality`、应用 Debug/Release Lint、Debug/Release 构建、测试 APK
  构建通过；编译完成类型检查。
- 隐私扫描、差异空白检查通过；排除明确不翻译的资源后，中英文资源键一致。
- 1.8 倍字体的中文超时页顶部与重连按钮截图已检查，没有省略或不可达操作。

本地证据位于忽略目录 `build/connection-limit-guidance/`，含红绿测试记录、门禁日志
和仅包含合成测试数据的界面截图。

## 交付及边界

新版 Debug APK 已通过保留数据的覆盖安装更新到手机主应用，没有在手机上运行
会安装/卸载测试目标的仪器测试，也没有为展示报错再次强杀真实服务器会话。
引导场景由离线 fixture 验证，本轮不声称重新完成真实服务器的 60 秒超时验收。

小米桌面先杀进程、再投递回调的问题仍存在。这次改善等待和恢复过程的说明，
不将厂商清理行为标为修复，也不自动更换身份或移除其他合法客户端。

本轮变更分类：生产代码为恢复预算常量、UI 消息解析与滚动布局及中英文资源；
测试为一个独立 Android 回归文件；文档为 README 双语版、ARCHITECTURE、
CHANGELOG、ADR-0009 和本报告；无新增配置变更。
