## 数据保留与产物

手机原安装为 0.11.0-m10 / versionCode 11，非 debuggable，与本机 Debug 签名不同。
本轮不卸载、不清数据、不覆盖该包；前后提取 APK 的 SHA-256 完全一致。
未通过 run-as 提取原应用的身份、密码或存储。为执行获授权的互通，从原应用已显示的表单读取端点；原密码栏为空。

当前源码复制到忽略的 `build/f1a/device-src/`，仅在本地副本修改 applicationId 为
`io.github.ts3mobile.app.f1adevicetest`、显示名称为“TS3 Mobile F1a 调试”。
namespace、生产业务代码、依赖和 39 个回归测试保持一致。旁装包有独立 Android UID、
Keystore 和新测试身份，使用本机开发签名，不是正式签名发布。
测试昵称为独立标记，未更改原应用的昵称或表单。

## 环境阻碍与处理

- 初次安装被小米系统拒绝：`INSTALL_FAILED_USER_RESTRICTED`。用户开启 USB 安装后又误选拒绝并不再提示。
- 实机开发者选项中 USB 安装总开关已开启；在“USB安装管理”解除 TS3 Mobile 的禁止记录后安装成功。
- 小米默认拒绝新调试包“后台弹出界面”，拦截测试框架启动 Activity。仅对独立调试包临时允许；测试结束已恢复为拒绝。
- 未更改全局输入法、系统字体、分辨率、密度或原应用权限。
- 收尾时 ADB 短暂重连；恢复连接后完成 APK 比对、临时文件清理和最终界面检查。

## 尚未覆盖

本轮真实收发验证的是独立 **Debug 包**；混淆 Release 在真机上只执行了身份/INI 探针，
没有以 Release 包建立本轮文字会话，也没有升级原 0.11.0-m10 安装。
服务器权限拒绝、断网重连、频道移动/回显字段差异仍主要依靠离线回归；没有把 Activity 重建当成网络重连。
未验证 Android 26/14、跨多种服务器实现、长时后台、真实语音听感、蓝牙或正式发布签名。
上述结果不替代 M11 发布验收。
