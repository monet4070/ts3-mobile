# 新用户 README 整理（2026-11-03）

## 修改前理解与范围

当前界面由 MainScreen 组合顶部菜单、SessionHeader/SessionAudioActions、
麦克风控制与频道/用户/聊天内容，收藏和输入弹窗独立。核对菜单、图标、资源文案、
聊天会话、麦克风设置、暂离与后台行为后，按用户在界面中的操作顺序扩充双语 README。

本轮只修改文档与已存在的合成 UI 截图的排版，不改生产代码、测试源码、构建/签名或版本。
GitHub 1.0.0 仍为准备状态，不将待发布功能写成旧 APK 已有能力。

职责评估：README 负责完整的新用户入口、界面导览和常用操作，尽量保持每份约 300 行以内；
详细故障排查、安装签名、隐私、开发验收仍链接已有独立文档，避免将维护者流程塞进使用步骤。

风险：误写菜单位置、混淆静音/暂离与麦克风关闭、使用过时/私人截图、暗示不存在的语言或
主题切换入口。逐项对照 Compose 与中英文资源，使用已验收的离线 fixture 截图，检查
文档目录锚点、本地图片、隐私扫描与空白；不把文档改动算作新的应用测试结果。
