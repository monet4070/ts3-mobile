2026-11-23。基线 `8bd1427`，候选为工作区开发改动，未发布。格式和门禁见 [ADR-0040](../decisions/0040-desktop-identity-input.md)。

离线日志及本地产物在 `build/desktop-identity-2026-11-23/`。合成数据未连接测试服，不替代独立官方桌面客户端证据。公开 Release 默认禁用；使用 `-PdesktopIdentityImportExperiment=true` 构建混淆 QA 包，不要作为普通 Release 发布。

使用连接探针后的候选 APK 又在 API 35 通过 16 项身份定向回归：真实身份 Activity 旋转后仍只显示原比较，不重开选择器、不写库；未确认关闭时丢弃预览，权威身份及回退点不变。全包执行曾有一次旧菜单测试在 Activity 交接期未找到 Compose 树，定向重跑通过。证据在 `build/floating-ptt-connected-2026-11-23/identity-targeted-api35.txt`。

旧备份另做 API 35 的隔离升级：由安装的 1.2.0 Debug（code 16）使用真实旧编解码器写合成 `.ts3mbak`，不重新播种文件；code 17 与 18 的正常备份读入／身份预检都恢复出同一合成材料，直升 code 18 也通过。原 vault 保留未变。这里只验证旧文件预检，完整写入/回退由独立的恢复事务和混淆测试覆盖。

## 单次人工验收

1. 用官方 Windows TS3 创建并导出**专用测试身份**。只需要一份 INI，留在本机私密目录；不索取用户现用身份。另记录桌面平台、客户端版本、界面显示的安全等级，offset 由本机文件读取，不共享私钥。
2. 在隔离测试服给该 UID 一项普通账号没有的测试权限。用 Android 混淆 QA 包从“设置 → 身份与备份 → 导入与恢复”选择该文件；核对 UID、offset、等级，取消一次后再导入确认。
3. 手动连接，确认原权限可用；断开后由本地旧身份执行回退，比较 UID。只回报“匹配/不匹配”、测试权限是否可用和固定异常类别。macOS 未走同样验证前不声明支持。正式签名的升级与旧 `.ts3mbak` 覆盖矩阵另见发布门禁。
