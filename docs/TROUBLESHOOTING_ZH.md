# 常见问题

[English](TROUBLESHOOTING.md) · [使用指南](USER_GUIDE_ZH.md) · [安装与升级](INSTALLATION.md)

## 安装与连接

| 问题 | 处理方法 |
| --- | --- |
| APK 安装失败或“与现有软件包冲突” | 核对 Android 版本、APK 完整性、包名与签名；保留原应用，先按安装指南排查，不要直接卸载 |
| 为什么手机有 TS3 Mobile 和 TS3 Mobile UI？ | 后者是独立调试包，身份和收藏各自保存；正式包不会导入旁装包的数据 |
| 地址填写正确但无法连接 | 核对语音端口、服务器密码与服务器状态；确认网络允许目标 UDP 流量，不要填 ServerQuery 端口 |
| 提示同一身份连接太多 | 使用其他客户端结束旧会话，至少等待提示建议的 60 秒后再手动重连；服务器清理可能更久，连续尝试可能触发临时封禁 |
| 划掉应用后还在服务器成员列表 | 厂商可能先杀进程，未交付正常退出回调；先在应用或通知中断开，旧会话可能要等待服务器超时 |
| 搜索不到某个用户或频道 | 搜索只覆盖当前已加载的服务器快照，权限不可见或尚未加载的内容不会出现 |
| 收藏存在但连接按钮不可用 | 先断开当前会话，并等待收藏读写完成；编辑与连接的可用条件不同 |

## 声音与后台

| 问题 | 处理方法 |
| --- | --- |
| 听得到别人，别人听不到我 | 检查麦克风模式、录音权限、频道发言权限和输入音量；按住模式需要持续按住按钮，门控可先降低阈值排查 |
| 门控安静时仍有录音指示 | 属正常行为：门控必须持续采集来判断音量；需要停止采集请选择关闭 |
| 无声音或声音从错误设备播放 | 检查收听/个人静音、用户音量、系统通话音量和当前音频路由；蓝牙中断或设备断开会安全静音，重新连接后请确认路由并手动取消收听静音 |
| 蓝牙音质与扬声器不同 | 双向通信可能使用通话音频路径，效果受系统、耳机与设备能力限制；不承诺所有蓝牙设备一致 |
| 扬声器有回声 | 优先用耳机并降低外放音量；检查设备回声消除状态。降噪与回声消除作用不同，实际效果需按设备测试 |
| 锁屏一段时间后断开 | 查看后台语音检查和厂商电池策略；按需调整省电设置，CPU 保持唤醒不能保证所有系统持续运行 |
| 重开应用后麦克风设置恢复默认 | 服务重建会恢复默认参数，属于当前设计；设置并非跨进程永久保存 |

## 消息与提醒

| 问题 | 处理方法 |
| --- | --- |
| 对方戳我没有弹窗或声音 | 前台查看应用提醒；后台检查系统通知权限、应用通知总开关、戳一下通知频道与勿扰模式。前台弹窗不保证系统通知声音 |
| 戳一下后没有切到聊天页 | 当前设计会保留原页面，以短提示反馈；历史仍可在对应私聊中查看 |
| 显示服务器接受，但对方没读到 | 服务器接受不等于送达回执或已读；确认对象在线、权限允许且会话身份没有变化 |
| 发送结果未知 | 应用不会自动重发，先向对方核实再决定是否重试，避免重复内容 |
| 重启后聊天记录不见了 | 聊天不落盘；手动退出、新会话、终态失败或进程结束会清空，不能从云端恢复 |
| 清除收藏密码后表单还记着密码 | 两者独立保存；若也要清空表单记忆，在连接表单删除对应内容并等待保存 |

仍有问题时，按[支持说明](../SUPPORT.md)提供版本、设备、复现步骤和脱敏诊断。
不要上传原始服务器地址、昵称、身份文件或密码；疑似安全漏洞走[私密报告](../SECURITY.md)。
