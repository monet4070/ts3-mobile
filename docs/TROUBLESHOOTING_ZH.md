# 常见问题

[English](TROUBLESHOOTING.md) · [使用指南](USER_GUIDE_ZH.md) · [安装与升级](INSTALLATION.md) · [1.3.0 更新说明](release/1.3.0/RELEASE_NOTES_ZH.md)

本页对应 **TS3 Mobile 1.3.0（versionCode 17）**。如仍在使用 1.2.0 或更早版本，部分 1.3.0 功能（浮窗 PTT、频道文件／聊天附件、本地聊天历史、按需功能帮助）尚未包含在旧包中。

## 安装与连接

| 问题 | 处理方法 |
| --- | --- |
| APK 安装失败或“与现有软件包冲突” | 核对 Android 版本（需 8.0+）、APK 完整性、包名（`io.github.ts3mobile.app`）与签名；**保留原应用**，先按[安装与升级](INSTALLATION.md)排查，切勿直接卸载 |
| 为什么手机同时有 TS3 Mobile 和 TS3 Mobile UI？ | 后者是独立调试／测试包，身份和收藏各自保存；正式包不会导入旁装包的数据 |
| 地址填写正确但无法连接 | 核对语音端口（通常 `9987`）、服务器密码与服务器状态；确认网络允许目标 UDP 流量，不要填 ServerQuery 端口 |
| 提示同一身份连接太多（错误码 521） | 结束其他客户端的旧会话，至少等待提示建议的 60 秒后再手动重连；服务器清理可能更久，连续尝试可能触发临时封禁。若发生在已确认切网后的自动重连阶段，1.3.0 会自动等待 60 秒后再试一次 |
| 划掉应用后还在服务器成员列表 | 部分厂商会直接杀进程而跳过正常退出回调；请始终通过应用内或连接通知的 **断开连接** 退出，旧会话可能需等待服务器超时 |
| 搜索不到某个用户或频道 | 搜索仅覆盖当前已加载的服务器快照，权限不可见或尚未加载的内容不会显示 |
| 收藏存在但“立即连接”不可用 | 1.3.0 的 **立即连接** 不会打断活动会话；请先断开当前服务器并等待收藏读写完成 |
| 修改收藏地址或频道后，原来保存的密码不见了 | 这是 1.3.0 的凭据隔离保护：修改地址或端口会清空草稿中的旧默认频道与两种密码；仅修改默认频道会清空频道密码。请为新目标重新输入，取消编辑可恢复原收藏 |

## 声音、蓝牙、切网与浮窗

| 问题 | 处理方法 |
| --- | --- |
| 听得到别人，别人听不到我 | 检查麦克风模式、录音权限、频道发言权限与输入音量；**按住**模式需持续按住按钮，门控可先降低阈值并用 **设置 → 麦克风设置 → 本机试麦** 排查 |
| 门控安静时仍有录音指示 | 属正常行为：门控必须持续采集以判断音量；完全停止采集请选择 **关闭** |
| 无声音或声音从错误设备播放 | 检查总收听静音、个人静音／音量、系统媒体音量及 **设置 → 输入与输出设备**（或 **语音播放**）下方的 **实际使用的音频设备**；蓝牙断开或自动回退会触发安全静音，重连后请确认路由并手动取消静音 |
| 为什么连着蓝牙耳机却用了手机麦克风？ | 默认媒体混播模式下，**自动选择麦克风** 优先使用手机麦克风以保持蓝牙媒体音质。如需使用蓝牙耳机麦克风，请进入 **设置 → 输入与输出设备**：若支持 LE Audio，可单独选择 **LE Audio 耳机麦克风**；若是传统蓝牙耳机，可在播放设备中手动选择 **蓝牙通话（使用耳机麦克风）**（传统通话模式音质可能下降，且不跨会话自动启用） |
| 选了「蓝牙通话（使用耳机麦克风）」后音质变差或重连后恢复了 | 音质下降是传统蓝牙通话（SCO）链路的系统限制，选回普通蓝牙播放即可恢复媒体音质；为避免误降音质，蓝牙通话选择不会保存到下次连接 |
| 扬声器有回声 | 优先佩戴耳机并降低外放音量；在 **设置 → 麦克风设置** 检查设备回声消除（AEC）状态（降噪与回声消除作用不同，实际效果因机型而异） |
| 切换 Wi-Fi 与移动数据时语音短暂停顿 | 1.3.0 在短暂切网（最长 2 秒）时会先尝试保留并探测原服务器会话，期间语音可能短暂停顿；若无法维持原会话则自动走断线恢复 |
| 锁屏一段时间后断开 | 查看 **设置 → 后台语音运行检查** 与厂商电池策略（例如设为无限制），按需开启 CPU 保持唤醒（不能保证所有 ROM 无限期后台存活） |
| 重开应用后麦克风采集模式回到“按住” | 属预期安全设计：输入音量、降噪、回声消除和门控阈值在保存后会持久保留，但采集模式不保存，新服务从 **按住** 启动且不自动采集 |
| 退到后台没有自动弹出浮窗 PTT | 在 **设置 → 浮窗 PTT** 允许“在其他应用上层显示”并开启 **退到后台时自动显示浮窗**；需已加入频道且麦克风空闲，主界面按返回触发需 Android 12+。也可从连接通知点 **开启浮窗** 手动召回 |
| 浮窗 PTT 无法按住发话 | 仅 **按住** 模式可按压右侧发话，其他模式下该区域仅显示状态；若 **本机试麦** 正在占用输入，请先停止试麦 |

遇到弱网断音或蓝牙异常，请按[离线音频诊断步骤](USER_GUIDE_ZH.md#离线音频诊断)标记断音并导出 JSON。

## 消息与通知

| 问题 | 处理方法 |
| --- | --- |
| 对方戳我没有弹窗或声音 | 前台查看应用内弹窗；后台检查系统通知权限、应用通知总开关、**戳一下提醒** 频道与勿扰模式 |
| 小米手机把连接卡片放进「更多通知」 | 这是系统通知过滤，不等于应用通知优先级低。连接后打开「更多通知」，轻向左滑 TS3 Mobile 卡片并按系统提示 **设为重要**（不要关闭「允许通知」） |
| 戳一下后没有跳转到聊天页 | 预期设计：提交后保留当前页签并给出简短提示，历史记录可在对应私聊查看 |
| 显示“服务器接受”，但对方没读到 | 服务器接受不等于送达或已读回执；请核对对方是否在线、权限是否允许及身份是否变更 |
| 发送结果未知 | 应用绝不自动重发，请先向对方确认是否收到再决定是否重发 |
| 复制聊天消息时带出了 `[b]` / `[url]` 等标记 | 预期行为：1.3.0 展示基础 BBCode 样式，长按复制始终保留原始文本；点击外部链接前会先弹窗核对目标地址 |
| 重启后聊天记录不见了 | 实时聊天仅存内存且无云同步。如需离线保留新消息，请事先在 **设置 → 本地聊天历史** 中开启（仅保存开启后的符合条件新文本，不补存旧消息） |
| 清除收藏密码后表单还记着密码 | 收藏与连接表单独立加密存储；若也要清空表单密码，请在连接表单删除对应字段并等待保存 |

## 文件、图片与功能帮助

| 问题 | 处理方法 |
| --- | --- |
| 频道文件列表或下载失败 | 核对服务器与频道权限，并请管理员确认文件传输端口可达；切换频道后重新打开文件列表。若列表超时且应用明确提示重连，请断开重连后再试 |
| 聊天附件无法下载 | 仅支持当前已连接服务器上的有效附件，单文件上限 **20 MiB**；不支持上传、自动下载或跨服取件 |
| 提示目标文件可能不完整 | 先检查已保存位置的文件；若已校验的下载仍在，可直接改存到另一处，否则重新下载 |
| 找不到新功能怎么用 | 打开 **设置 → 帮助与关于 → 功能帮助**（支持离线查阅与控件高亮定位），详见[文件与服务端图片指南](USER_GUIDE_ZH.md#文件与服务端图片) |
