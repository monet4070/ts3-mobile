API 35 隔离模拟器的富文本、收藏、凭据和会话门禁定向测试首轮 20 项通过；对最终交互又跑 4 项，验证聊天行点击、确认/取消、复制原文及活动会话不被替换。29 项 Python 检查通过。证据在 `build/ts6-borrow/`，不是实机音频、文件互通或发行证据。

离线频道快照的 JVM 定向测试覆盖密文、地址归一、端口隔离、淘汰、删除和格式上限。API 35 测试覆盖显式保存、失去在线会话后的选择、迟到读结果隔离，以及清除列表不修改收藏。未使用真实服务器、频道名或凭据。

聊天历史用合成身份和消息通过 JVM 定向测试；API 35 的聊天与设置回归共 23 项通过，包括真 Keystore 密文、切换身份、按会话删除、关闭后重新打开存储验证及备份排除。

API 35 的频道文件界面 5 项通过：导航和取消、权限拒绝、文档提供方字节一致、不可写时清理、界面替换竞态。
在官方隔离实例另实跑 1 项 JVM 探针，未跳过：文件实际增长期间及完成后收到已知 Opus 帧，长度和哈希匹配，拒绝与换频道失效正确。实例已停止。这证明现有 TS3j 能支撑这条只读路径，不代表已经验证 Android 真机播放和保存。

Android 16 实机通过 USB 回环实跑 1 项：真实 `AudioTrack` 播放头推进、下载期间多次观察到输出采样与文件同时增长，测试文档提供方的 8 MiB 文件哈希匹配，取消清理、权限拒绝和旧访问端口失效均通过。没有外放听感验收，也不把测试提供方当作系统文件选择器的验收。测试用包、桥和服务端均已清理。

在无 JitPack 的源码回退路径上，本地重跑协议单测、Release Lint 与 R8，保留了 APK 哈希和 API 35 ARM64 ART 证据（`build/ts6-borrow/source-release/`）。CI 新增的六组功能用例用默认 Debug 包在本地一起跑了 18 项，全部通过；托管 CI 未执行。

附件原生选择器补验后，用默认固定依赖、未启用媒体探针的 Debug APK 重跑 CI 的九个借鉴项回归类，API 35 共 22 项通过；完整 Python 检查 33 项通过。最终成品资源表中普通 Debug 与 Release 的媒体探针都为 `false`，未触发托管 CI 或发布。

国际化显示修复后的最终质量检查按默认打包路径运行 `quality`、三个模块单测、Android Lint 和 Debug／混淆 Release／Android 测试 APK 构建：898 项单测通过，6 项显式夹具用例按设计跳过；Python 33 项和仓库隐私扫描通过。API 35 重跑 CI 的九个借鉴项回归类，23 项通过。官方回环实跑共 5 项通过、无跳过：两份桌面真实样本、合成附件、频道文件／并发语音和资源。最后两项在长时实例拒绝连接后，用相同隔离配置重启才通过，保留首次失败证据。普通 Debug 与 Release 的媒体探针资源仍为 `false`。未发布，未切换 TS3j。

## 新增界面精调

外链确认、收藏与离线频道、聊天历史、频道文件、附件和图片预览复用 TS3 Mobile 既有主题、卡片与安全区弹窗。列表不再堆叠胶囊按钮；主操作、低强调操作和破坏性确认分开。大字号下收藏的服务器地址单独换行，连接操作不挤压昵称。文件界面区分下载中、待选保存位置、保存中与已保存，文件夹提供读屏语义。

新增轮廓图标的 SVG 源文件在 `assets/icons/`，Android 使用一一对应的 VectorDrawable。未改变存储格式、网络行为、权限或媒体开关。API 35 的中文浅色与 320 dp／1.8 倍字号深色实拍用隔离演示数据，前后对照和测试证据在本机忽略目录 `build/feature-ui-refine/`。

界面精调后通过 42 项 Android 回归、320 dp 大字收藏专项、898 项 JVM 单测（6 项显式夹具跳过）、33 项 Python 检查、Ktlint、Android Lint、隐私扫描和 Debug／混淆 Release 构建。图片用例分别等待服务器、频道和头像预览实际显示；普通 Debug 和 Release 的媒体开关仍关闭。
