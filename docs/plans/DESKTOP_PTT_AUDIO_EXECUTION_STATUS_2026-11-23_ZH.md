## 把人工工作合并成两轮

1. **一份专用桌面身份、一个测试服。** 在官方 Windows 桌面端导出一次，完成 Android 对照、权限、回退。若计划声明 macOS 支持，再加一个 macOS 样本。不要传真实 INI、真实凭据或远端录音。
2. **一次借机窗口，两家厂商。** 用同一测试频道先完成 P0 实听与故障切换，再跑 A1 音频对照（Xiaomi 14＋AirPods、固定 A2DP；有线或 USB 对照）。脚本校验 A/B 是否真的分开，只人工记录首句漏失、主观听辨、声学延迟、录音指示器和 OEM 事件。P1/P2 要等 P0 通过才进入正式实现和针对性复测；A3 同样要等 A1 单声道基线。两条门槛都不挡身份或独立收藏热修。

**最后由发布负责人签收。** 用对应发行工件核查正式签名和递增的版本号，并在真机覆盖升级后核对身份、旧备份、收藏和应用内 PTT；可与借机窗口合并，不用重复跑合成矩阵。收藏热修保持独立；身份、浮窗和音频实验只按各自通过的范围开放。协议精确 UDP 计时的正式交付还需批准并固定 fork 新版本，现有正式依赖不变。
